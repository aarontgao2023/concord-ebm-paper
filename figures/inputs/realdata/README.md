# ADNI and NACC aggregate inputs

This folder is empty in the repository. The scripts for Fig. 4, Fig. 5, Tables 2 and 3,
Supplementary Figs 2 and 3 and Supplementary Tables 3-5 read aggregate results of the ADNI and
NACC analyses from here (counts, orderings, rates and intervals; no participant-level data).
These files are not distributed with the code; see the Data availability statement of the
article. The list of files, and which figure or table uses each, is in `figures/README.md`.

Everything in this folder except this README is ignored by git (`figures/.gitignore`).
