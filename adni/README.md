# adni

The ADNI reanalysis: eight-way recomputation of published between-genotype ordering comparisons
(two consensus arms × two estimators × two reference compositions), a composition-subsampling check, and
calibration of the simulator to the observed cohort. Scripts will be added here once data access is in place.
No ADNI data, subject identifiers or derived per-subject tables are stored in this repository (ADNI Data Use
Agreement).
